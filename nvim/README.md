# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Requirements

- Neovim >= 0.12 (uses the `nvim-treesitter` `main` branch)
- `tree-sitter` CLI >= 0.25 — nvim-treesitter compiles parsers via `tree-sitter build`;
  the apt-shipped 0.20.x is too old. Install with `npm install -g tree-sitter-cli`
- A C compiler (`cc`) and `git`
